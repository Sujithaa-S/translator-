# 🌐 Voice Translator

A simple and user-friendly **English ↔ Tamil Voice Translator** application and website that helps users translate speech between English and Tamil.

## 🌐 Live Website

[🔗 Open Voice Translator Website](https://sujithaa-s.github.io/translator-/)

## 📥 Download the App

The Android application is available as an APK file.

[⬇️ Download Voice Translator APK](./Translator.apk)

## ✨ Features

- 🎤 Voice input using microphone
- 🇬🇧 English → Tamil translation
- 🇮🇳 Tamil → English translation
- 🔊 Listen to translated text
- 🗑️ Clear input and translation
- 📱 Mobile-friendly interface
- 🌐 Web-based translation
- ⚡ Simple and easy-to-use interface

🎯 About the App
Voice Translator is a voice-based translation application designed to make communication between English and Tamil easier.
Users can speak in English or Tamil, convert their speech into text, translate it into the selected language, and listen to the translated result.
The project provides both a web version and an Android application.
